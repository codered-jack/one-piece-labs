This is the lab for the ***Labels and selectors*** lesson. This machine is a one-node Kubernetes cluster, with `kubectl` set up. Two pods are already running on it: a `lookout` and a `cook`. You'll:

- start pods with **labels**, from the command line and from a manifest
- pick pods out with a **selector**
- change a pod's label
- delete pods by label

Each step ends with a **Check** button that looks at the cluster and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
