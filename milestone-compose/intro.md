This is the lab for the ***Milestone: Bounty Board with Compose*** lesson. This machine has Docker installed. While you read this, it's installing the Compose plugin. You'll run the Bounty Board, a four-part app, with Docker Compose:

- get the code
- start all four parts with **one command**
- post a bounty, and keep it through a restart
- take the **cache** away, and see the app carry on
- clear everything, data included

Each step ends with a **Check** button that looks at the app and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
