This is the lab for the ***Networking and the localhost trap*** lesson. This machine has Docker installed. You'll get containers talking to each other, and to you:

- create a **network** of your own
- start a **Den Den Mushi**, a server that answers every call
- call it **by name** from another container
- **publish a port**, so the machine can call it too
- fix a server that only listens on **localhost**

Each step ends with a **Check** button that calls your containers and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
