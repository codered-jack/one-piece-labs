# Kubernetes environment spike

This scenario measures what the Kubernetes lab machine offers. Nothing here is a lesson.

The terminal runs checks for two to four minutes: cluster details, build tools, whether a volume claim binds, and how long metrics-server takes to start serving numbers.

Wait until the terminal prints `=== BASE CHECKS DONE ===`, then press **Start**. Each following step installs one Gateway API controller and prints its timings. Wait for `STEP DONE` before pressing **Next**.
