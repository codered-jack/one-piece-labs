This is the lab for the ***Pods*** lesson. This machine is a one-node Kubernetes cluster, with `kubectl` set up. You'll run the Den Den Mushi in a **pod**:

- write the pod's **manifest**, and apply it
- find the pod's address
- call it from inside, with `kubectl exec`
- give it a second container, a **lookout**, in a pod of its own
- delete both pods

Each step ends with a **Check** button that looks at the cluster and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
