This is the lab for the ***Deployments*** lesson. This machine is a one-node Kubernetes cluster, with `kubectl` set up. You'll keep three copies of the Den Den Mushi running with a **Deployment**:

- write the Deployment, and apply it
- find the **ReplicaSet** it made
- delete a pod, and watch a new one take its place
- take a pod out of the Deployment with a label
- delete the Deployment

The lesson also stops a machine. This cluster has only one, so that part stays in the lesson.

Each step ends with a **Check** button that looks at the cluster and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
