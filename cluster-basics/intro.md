This is the lab for the ***Cluster, control plane, namespaces*** lesson. This machine is a Kubernetes cluster of its own, with `kubectl` set up. You'll survey it:

- list the cluster's **node**
- find a part of the **control plane** among the cluster's own pods
- create a **namespace**
- find a pod hidden in another namespace, and clear it out

This cluster has a single node. It's the control plane and the worker at once.

Each step ends with a **Check** button that looks at the cluster and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
