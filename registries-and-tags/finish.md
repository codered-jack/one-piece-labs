# Lab complete

You just:

- ran a **registry** of your own, and asked it what it holds with `curl`
- gave an image a name that includes the registry with `docker tag`, and sent it with `docker push`
- shipped a new version and watched **`latest`** move to it
- pinned version 1.0 by its **digest**, the one name that can never point anywhere else
