This is the lab for *What a container really is*. This machine runs Ubuntu and already has Docker installed. You'll:

- run a container from the `alpine` **image**
- check which Linux a container has, and whose **kernel** it uses
- start a container in the background, and find its process from the machine

Each step ends with a **Check** button that looks at the machine and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
