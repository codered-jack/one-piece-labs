This is the lab for the ***What a container really is*** lesson. This machine runs Ubuntu, and Docker is already installed. You'll:

- run a container from the `alpine` **image**
- check which Linux a container has, and whose **kernel** it uses
- start a container in the background, and find its process from the machine

Each step ends with a **Check** button. It looks at the machine, and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
