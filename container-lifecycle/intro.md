This is the lab for the ***Container lifecycle*** lesson. This machine has Docker installed. You'll keep a container running and look after it:

- start a **lookout** that prints a report every 2 seconds
- read its reports with **docker logs**
- step inside it with **docker exec** and leave a note
- **stop** it and **start** it again, and see what survives
- run a container that keeps crashing, and let a **restart policy** bring it back

Each step ends with a **Check** button that looks at your containers and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
