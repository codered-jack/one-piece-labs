This is the lab for *Images: the recipe card*. This machine has Docker installed. You'll:

- pull an image by its **tag**
- count the **layers** an image is made of
- write a file inside a container, and find it in the container's **writable layer**
- remove the container and the image you used

Each step ends with a **Check** button that looks at the machine and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
