This is the lab for the ***Docker Compose: one file, one command*** lesson. This machine has Docker installed. While you read this, it's installing the Compose plugin. You'll run containers from a `compose.yaml` instead of long `docker run` commands:

- write the **Den Den Mushi** down in a `compose.yaml`
- start it with **one command**
- add a **lookout** that calls it by name, and writes a logbook in a **volume**
- take the app down and back up, and keep the logbook
- clear everything, logbook included

Each step ends with a **Check** button that looks at your app and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
