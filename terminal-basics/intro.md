This is the lab for the ***Your terminal in 20 minutes*** lesson. You'll practise the lesson's ideas on a real Linux machine:

- make a **folder** and a file, and move around
- start a **process** in the background, and find its PID
- see which **ports** are taken
- move a server from **localhost** to every address
- set an app's port with an **environment variable**

Each step ends with a **Check** button. It looks at the machine, and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
