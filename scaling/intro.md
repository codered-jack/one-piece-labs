This is the lab for the ***Scaling up and down*** lesson. This machine is a one-node Kubernetes cluster, with `kubectl` set up. The `den-den` Deployment from the ***Deployments*** lab is already running, with three copies. Its file is `~/fleet/den-den-deployment.yaml`. You'll:

- scale it up to five copies, and down to two
- change the count in the file, and apply it
- scale it to zero
- bring it back from the file

Each step ends with a **Check** button that looks at the cluster and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
