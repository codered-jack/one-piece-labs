This is the lab for *Build your own image*. This machine has Docker installed, and the folder `~/wanted` holds the wanted-poster app from the lesson. You'll build four versions of its image:

- `v1`: a first **Dockerfile** that prints Luffy's poster
- `v2`: an **ENTRYPOINT**, so you can pass any name
- `v3`: a default bounty baked in with **ENV**
- `v4`: the whole folder copied in, with a **.dockerignore** that keeps the secrets file out

You'll write the Dockerfile in a terminal editor. `nano Dockerfile` opens one: type or paste, then press `Ctrl+O` and `Enter` to save, and `Ctrl+X` to quit.

Each step ends with a **Check** button that runs your image and tells you whether the task is done. Stuck? Every step has a **Tip**, and a **Solution** if you need it.

Press **Start** when you're ready.
